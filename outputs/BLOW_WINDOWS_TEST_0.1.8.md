# BLOW 0.1.8 — 설치본 로그인 연결 설정 복구

## 원인

- 사용자가 본 ‘앱 연결 설정이 필요합니다’ 화면은 공개 연결 URL 또는 공개 키가 빌드에 없는 경우 표시됩니다. 비밀번호 오류나 회원권 차단 화면이 아닙니다.
- 원래 프로젝트의 `apps/desktop/.env.local`에는 두 값이 존재했지만, 현재 Git worktree에는 파일이 없었습니다. Git에서 제외하는 환경 파일은 worktree로 자동 복사되지 않습니다.
- 0.1.7 설치 패키지의 화면 코드에 공개 연결 URL과 공개 키가 모두 없음을 확인했습니다. 당시 가짜 인증을 사용하는 화면 테스트로는 이 누락을 발견하지 못했습니다.

## 수정 파일

- `apps/desktop/.env.local` (로컬 전용, Git 제외): 기존 프로젝트에서 공개 연결값 두 개만 복원했습니다. 비밀 키는 복사하지 않았으며 실제 값은 보고서나 로그에 출력하지 않았습니다.
- `apps/desktop/electron.vite.config.ts`: 환경 파일 위치를 명확히 지정하고, 화면에 전달하는 환경변수를 두 공개 연결값으로 제한했습니다. 빌드 전에 공개 설정을 검사합니다.
- `apps/desktop/scripts/public-build-config.ts`, `public-build-config.test.ts`: 설정 누락·공백·잘못된 URL·비밀 키 형태를 거부합니다. 오류 메시지에는 입력값을 포함하지 않습니다.
- `apps/desktop/scripts/check-packaged-login.cjs`: 실제 패키지의 화면 코드와 preload를 읽는 로그인 화면 검사. 격리된 임시 프로필·숨김 Electron 창을 사용하며 외부 통신과 로그인 제출은 하지 않습니다.
- `README.md`: 환경 파일과 worktree 빌드 준비 안내.
- `apps/desktop/package.json`, `package-lock.json`: 버전 0.1.8.
- `outputs/BLOW_WINDOWS_TEST_0.1.7.md`: 해당 설치파일 사용 중지 안내 추가.

ponytail 원칙으로 기존 환경변수 방식만 복구하고 짧은 빌드 사전 검사를 추가했습니다. Supabase 스킬에 따라 공개 키와 관리자 비밀 키를 구분했습니다. 공개 키는 배포 앱에 사용할 수 있지만 비밀 키는 포함하면 안 됩니다. [Supabase 공식 안내](https://supabase.com/docs/guides/getting-started/api-keys). Vite 환경변수는 빌드 시 화면 코드에 반영됩니다. [Vite 공식 안내](https://vite.dev/guide/env-and-mode).

## 확인 결과

- 전체 타입 검사 통과.
- 단위 테스트 33개 파일, **425개 통과**.
- 환경변수를 의도적으로 비운 실제 데스크톱 빌드가 실패하는 것을 확인했습니다.
- 기존 공개 설정을 이용한 인증 설정 읽기 요청이 HTTP 200으로 응답했습니다. 회원정보 조회·로그인·가입·데이터 변경은 하지 않았습니다.
- **0.1.8 패키지의 실제 로그인 화면 확인**: 이메일·비밀번호 입력 가능, 회원가입 화면 전환 가능, 연결 설정 오류 화면 미표시. 화면 캡처도 확인했습니다.
- 패키지에 기존 공개 연결값이 포함되고 메인·preload·화면 코드가 최신 빌드와 일치함을 확인했습니다. 환경 파일·Chrome 프로필·비밀 키 문자열은 포함하지 않았습니다.
- 설치파일 압축 검사 통과 (`Everything is Ok`). 실행형 설치파일의 아카이브 뒤 추가 데이터 경고도 출력되었습니다.
- 기존 사용자 프로필, 저장된 API 키, 회원정보, 네이버 글, DB/RLS/인증 정책은 변경하지 않았습니다.
- 실제 사용자 로그인과 네이버 글 작성·임시저장은 이번 검사 범위가 아닙니다. 앞선 키워드 비차단 보고 변경은 유지하며, 스티커 삽입 문제는 별도 미해결 사항입니다.

## 설치 안내

1. 미저장 네이버 내용이 있다면 먼저 확인·보존합니다.
2. BLOW와 전용 Chrome을 닫습니다.
3. `apps/desktop/release/BLOW-Setup-0.1.8-x64.exe`로 업데이트합니다. **기존 BLOW를 먼저 제거하지 마세요.** 제거 시 로컬 설정·프로필이 삭제될 수 있습니다.
4. 로그인 화면이 보이면 기존 BLOW 계정으로 로그인합니다. 사용자 PC에서 Supabase 설정을 새로 입력할 필요는 없습니다.
5. 미서명 내부 테스트 설치파일이므로 Windows 보안 경고가 나올 수 있습니다. 자동 설치는 하지 않았습니다.
