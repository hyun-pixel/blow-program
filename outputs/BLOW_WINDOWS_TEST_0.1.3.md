# BLOW 0.1.3 Windows 테스트 빌드

## 수정 내용

- 실제 네이버 로그인 후 `글쓰기 화면 열기` 단계에서 `locator.count: Frame was detached` 오류를 재현했습니다.
- 글쓰기 링크 탐색 중 사라진 보조 프레임의 결과만 제외합니다. 해당 프레임에서 일부 찾았던 링크도 폐기합니다.
- 살아 있는 프레임의 오류, 글쓰기 버튼 부재, 로그인 계정·목적지 검증은 그대로 유지합니다.
- 기존 사용자 데이터, 작성 목록, 네이버 임시글은 변경하지 않았습니다.

## 검증

- 수정 전 회귀 테스트 3건 실패 → 수정 후 통과.
- 전체 자동 테스트: 30개 파일, 347개 테스트 통과.
- 전체 워크스페이스 타입 검사 통과.
- 오프라인 Chrome: 연속 2회 새 글쓰기 탭 진입, 원래 탭 유지 확인.
- 새 설치파일의 Electron과 패키징된 어댑터: 실제로 분리된 가상 Chrome 프레임이 있어도 글쓰기 진입 성공.
- 승인된 실제 로그인 진단: 등록 블로그 일치 → 글쓰기 화면 진입 성공 (`WRITER_READY`).
- 실제 글 입력·이미지 생성·임시저장·발행과 유료 AI 호출은 실행하지 않았습니다. 전체 작성 과정의 실사용 검증은 별도로 필요합니다.

## 설치 및 재테스트

1. BLOW와 BLOW 전용 Chrome을 닫습니다.
2. `apps/desktop/release/BLOW-Setup-0.1.3-x64.exe`를 실행해 업데이트합니다.
3. 기존 앱을 먼저 제거하지 마세요. 제거 시 로컬 설정과 로그인 정보가 삭제될 수 있습니다.
4. 블로그 세팅에서 연결을 확인한 뒤 새 글 1개로 테스트합니다. 자동 작성 시 사용자의 OpenAI API 사용료가 발생합니다.
5. 기존 실패 항목은 중복 작성을 방지하기 위해 자동 재실행하지 않습니다. 필요한 주제와 설정으로 새 항목을 등록하세요.

내부 테스트용 미서명 설치파일입니다. Windows 보안 경고가 나타날 수 있습니다. 외부 업로드·배포와 Git 커밋·푸시는 실행하지 않았습니다.
