# BLOW 0.1.2 네이버 글쓰기 전환 수정판

작성일: 2026-09-28

## 변경 사항

- 자동 작성 시작 시 네이버 홈 이동·화면 재구성 때문에 연결 확인이 일시적으로 실패하면 기존 로그인 확인의 재시도 절차를 재사용한다.
- 연속 확인 실패는 최대 5회에서 중단한다. 글 생성·저장 자체를 재시도하는 기능은 아니다.
- 로그인 만료·등록 블로그 불일치는 글쓰기 전에 중단한다. 새 탭이 닫혀도 기존 글쓰기 탭으로 옮겨가거나 작성 중인 글을 지우지 않는다.
- 오류가 계속되면 새 탭 열기 / 블로그 연결 확인 / 글쓰기 화면 열기 중 멈춘 단계를 표시한다. 원본 브라우저 오류·계정 주소·토큰은 화면에 표시하지 않는다.

## 확인한 범위와 한계

- 수정 전: 화면 전환 오류를 주입한 자동 작성 회귀 테스트에서 사용자가 본 일반 연결 오류가 재현됐다.
- 수정 후: 전체 단위 테스트 342개 및 전체 타입 검사 통과.
- 별도 Chrome과 가짜 네이버 페이지를 사용하는 오프라인 검사에서 글쓰기 화면 2회 진입 및 기존 탭 보존을 확인했다. 외부 요청은 모두 차단했다.
- 실제 사용자 환경의 원본 오류 기록은 없어 동일 원인인지는 확정하지 않았다. 실제 네이버 로그인·글 생성·임시저장 및 설치 업데이트는 사용자의 후속 확인이 필요하다.
- 유료 AI 호출, 실제 네이버 글 생성·저장·발행, 사용자 데이터 변경은 실행하지 않았다.

## 설치 및 재확인

1. 실행 중인 BLOW 작업을 마치고 프로그램을 완전히 종료한다.
2. 기존 BLOW를 먼저 제거하지 말고 `apps/desktop/release/BLOW-Setup-0.1.2-x64.exe`를 실행한다. 별도 제거를 하면 저장한 설정·API 키·Chrome 로그인 정보가 삭제된다.
3. 새 BLOW를 실행하고 블로그 세팅에서 네이버 연결을 확인한다.
4. 네이버 임시저장 목록에 기존 작업 결과가 없는지 먼저 확인한다. 실패한 작업은 자동으로 재실행하지 않는다.
5. 한 글만 실행해 홈에서 글쓰기 화면으로 넘어가는지 확인한다. 전체 목록을 반복 실행하지 않는다. 연결 확인이 성공해 글 생성 단계에 들어가면 OpenAI API 비용이 발생한다.
6. 다시 실패하면 BLOW의 오류 문구 전체와 Chrome 화면을 전달한다. 새 문구 끝의 중단 단계도 포함한다.

설치파일은 코드 서명이 없는 내부 테스트용이다. Windows 게시자·보안 경고가 나타날 수 있다. 고객 배포·홈페이지 등록은 실제 테스트 완료 후 별도로 진행한다.
