# BLOW 네이버 연결 POC 결과

> 버전: 0.1
> 작성일: 2026-09-03
> 상태: 비로그인 공개 경로 검증 완료, 로그인 계정 검증 대기

## 1. 이번 단계의 목적

실제 글을 입력하기 전에 BLOW 전용 Chrome에서 네이버 로그인 상태, 등록 블로그 일치 여부와 글쓰기 화면 진입 가능 여부를 분리해 확인한다.

## 2. 구현한 범위

1. 네이버 블로그 주소 형식 검증
2. 모바일·게시물 주소에서 블로그 ID 추출
3. 외부 도메인과 HTTP 주소 차단
4. BLOW 전용 Chrome 프로필 실행
5. 사용자의 수동 로그인 대기
6. 네이버의 내 블로그 주소와 등록 블로그 ID 비교
7. 글쓰기 문구와 허용된 이동 주소를 함께 확인
8. 확인된 글쓰기 링크 클릭
9. PostWriteForm 화면 진입 확인
10. Chrome 수동 종료 감지와 세션 초기화

제목·본문·이미지 입력, 임시저장과 최종 발행은 이번 단계에서 실행하지 않는다.

## 3. 안전 경계

- 일반 Chrome 프로필을 사용하지 않는다.
- 네이버 아이디와 비밀번호를 앱에서 입력받지 않는다.
- 렌더러는 임의 주소나 선택자를 자동화 코드에 전달할 수 없다.
- https://blog.naver.com의 허용된 경로만 사용한다.
- 글쓰기 링크가 없거나 화면 주소를 확실히 확인하지 못하면 중단한다.
- 발행 버튼 선택자와 발행 명령은 포함하지 않는다.
- 입력한 블로그 주소는 이번 POC에서 디스크에 저장하지 않는다.

## 4. 검증 결과

- 주소·로그인 URL·글쓰기 경로 단위 테스트: 통과
- 비로그인 네이버 공개 화면 스모크 테스트: 통과
- 키보드 제출과 오류 입력 포커스: 통과
- 데스크톱·모바일·다크 모드 레이아웃: 통과
- 640px 유효 폭에서 가로 넘침 없음
- 주요 버튼 높이 44px 이상
- 오류 알림은 하나의 라이브 알림 경로만 사용

## 5. 아직 확인하지 않은 항목

개발용 네이버 계정으로 전용 Chrome에 직접 로그인한 뒤 다음 항목을 확인해야 한다.

1. 내 블로그 주소가 등록 주소와 일치하는지
2. 글쓰기 링크가 로그인 상태에서 동일하게 노출되는지
3. 실제 글쓰기 화면이 PostWriteForm 경로로 열리는지
4. 앱과 PC를 재시작해도 전용 프로필의 로그인 상태가 유지되는지
5. Chrome 최신·직전 정식 버전에서 반복 성공하는지

이 검증에는 개발 전용 네이버 계정이 필요하지만 비밀번호를 코드, 문서와 채팅에 입력해서는 안 된다.
