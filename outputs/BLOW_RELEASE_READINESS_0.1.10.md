# BLOW 0.1.10 배포 준비

확인일: 2026-09-30

기능 검수와 소스 정리는 완료했지만, 정식 공개 배포는 보류합니다. 사용자가 두 글 연속 작성·네이버 임시저장·작업 내역·글 배치를 정상 확인했습니다. 현재 설치파일에는 정식 코드 서명이 없고, 지인 PC에서는 Windows 보안 차단이 보고됐습니다.

## 설치파일

- 버전: 0.1.10, Windows x64 NSIS 설치파일.
- 위치: `apps/desktop/release/BLOW-Setup-0.1.10-x64.exe`.
- 크기: 117,304,827바이트, 약 117.3MB.
- SHA-256: `1F1BA5303D1C4D4BB9CDAA71B7213B5BBB98AF70724709B2A899E5119637441A`.
- Authenticode 서명 상태: `NotSigned`.

사용자가 검수한 파일을 보존했습니다. 이번에는 버전을 올리거나 설치파일을 다시 만들지 않았습니다. 현재 소스를 다시 빌드해 기존 설치용 앱의 실행 파일 20개와 비교했고 모두 일치했습니다. 환경 파일과 개인 Chrome 프로필은 패키지에 포함되지 않았습니다.

SHA-256은 파일이 동일한지 확인하는 값이며 정식 서명이나 안전성 보증을 대신하지 않습니다. 서명을 적용한 최종 파일은 해시가 바뀌므로 다시 계산해야 합니다.

## 포함된 개선

- 로그인 후 새 글쓰기 화면 진입과 다음 글 전환을 보완했습니다.
- 본문 길이와 키워드 횟수 차이는 저장 후 안내합니다. 이를 맞추기 위한 유료 재생성을 자동 실행하지 않습니다.
- 오류 후 입력칸 복구, 실패 항목 재생성 및 설정 불러오기를 제공합니다. 재생성은 비용과 중복 저장 안내를 확인한 뒤 실행합니다.
- 이미지를 본문 중간에 나누고 모바일 독자를 위해 문단 사이 여백을 넣습니다.
- 스티커의 지연 표시와 화면 재구성에 따른 잘못된 실패 판정을 줄였습니다.
- 저장 버튼 클릭만으로 완료 처리하지 않고 실제 저장 완료 신호를 확인한 뒤 작업 내역을 기록하고 다음 글로 이동합니다.
- 네이버 저장 후 작업 내역만 실패한 경우 글을 재생성하지 않고 기록만 복구할 수 있습니다.
- 로그인 공개 연결값 누락 또는 비밀 키가 포함된 빌드를 사전에 중단합니다.

최종 발행은 자동 실행하지 않습니다. 저장 후 사용자가 네이버에서 내용과 이미지 사용 권한을 확인하고 직접 발행합니다.

- 스티커: 9개 모의 시나리오 통과. 6개 및 10개 삽입, 다섯 번째 지연, 화면 재구성, 누락·중복·위치 오류를 검사했습니다.
- 글쓰기 전환: 두 글용 새 탭 진입과 기존 탭 보존을 모의 환경에서 확인했습니다.

- 실제 0.1.10 패키지: 로그인 입력칸과 회원가입 화면 전환, 연결 설정 오류 미표시를 확인했습니다. 로그인은 제출하지 않았습니다.
- 홈페이지 로컬 검사: 6개 경로, 링크·자산·비공개 베타 안내와 다운로드 비활성 상태 확인.

에이전트 검증에는 격리된 임시 프로필과 모의 데이터를 사용했습니다. 실제 네이버 글·회원 데이터 변경, 유료 AI 호출은 하지 않았습니다. 실제 두 글 연속 저장 성공은 별도로 사용자가 확인한 결과입니다. 이 결과만으로 다른 PC와 모든 네이버 화면에서의 정상 동작을 보장하지 않습니다.

## 지인 테스트와 업데이트 안내

1. 기존 BLOW와 전용 Chrome을 닫고 0.1.10 설치파일로 업데이트합니다. 기존 프로그램을 먼저 제거하지 마세요. 제거하면 로컬 설정과 로그인 프로필이 삭제될 수 있습니다.
2. 테스트 참여자 본인의 BLOW 계정·네이버 계정·OpenAI API 키를 사용합니다. 관리자 계정, 다른 사람의 API 키, Chrome 프로필이나 `.env.local`은 전달하지 않습니다.
3. 계정 이용권이 유효한지 확인하고 블로그 세팅과 AI·네이버 연결을 완료합니다. 실제 글과 이미지 생성에는 본인의 OpenAI API 이용료가 발생합니다.
4. 두 주제를 목록에 넣어 한 번 시작한 뒤, 두 글 모두 네이버 임시저장 목록과 BLOW 작업 내역에 있는지 확인합니다. 작업 중 PC 조작·절전·종료는 피합니다.
5. 저장 여부가 불확실하면 재생성부터 하지 말고 네이버 임시저장 목록을 먼저 확인합니다.

현재 파일은 내부 테스트 산출물입니다. 지인 PC의 설치 차단은 아직 해결 확인을 받지 못했습니다. 보안 기능 끄기를 일반 고객 설치 절차로 안내하거나 이 파일을 정식 배포본으로 표시하지 않습니다.

## 공개 배포 전에 남은 조건

1. 개인 자격으로 신청할 정식 코드 서명 공급사·게시자 이름·비용 확정 및 별도 구매 승인.
2. 최종 앱과 설치파일 서명, 타임스탬프와 파일 무결성 검증. 과거 조직 기준 서명 결정은 그대로 신청하지 않습니다.
3. 깨끗한 별도 Windows PC에서 설치·로그인·두 글 연속 임시저장·업데이트 검수. 지인의 설치 성공도 아직 미확인입니다.
4. 파일 호스팅 위치·다운로드 주소·홈페이지 변경 범위와 공개 시점 승인.

정식 서명만으로 모든 Windows 경고가 즉시 사라진다고 약속하지 않습니다. 현재 단계에서 일반 고객 배포 준비가 모두 끝났다고 판단하지 않습니다.
