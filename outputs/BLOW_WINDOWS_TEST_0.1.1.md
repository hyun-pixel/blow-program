# BLOW 0.1.1 Windows 내부 테스트

작성일: 2026-09-28

## 포함 내용

- 블로그 세팅 중심의 밝은 UI와 Cafe24 Supermagic 글꼴
- 상품·서비스명 및 선택 가격 저장, 글별 상품 선택
- 주제 상세 추천, 이미지·인용구·스티커·구분선 사전 설정
- 한 글 또는 여러 글 자동 작성·검사·네이버 임시저장
- 실행 확인 전 입력값 보존 및 취소·재시도 시 중복 추가 방지

## 설치

1. 실행 중인 BLOW에서 작업을 마치고 프로그램을 종료한다.
2. 기존 BLOW를 먼저 제거하지 말고 새 BLOW-Setup-0.1.1-x64.exe를 실행한다.
3. 설치 안내를 따라 현재 Windows 사용자 계정에 설치한다.
4. 설치 완료 후 BLOW를 실행한다. Chrome과 인터넷 연결도 필요하다.

기존 제거 프로그램은 BLOW 로컬 데이터, 저장한 API 키, 전용 Chrome 로그인 정보를 삭제하도록 구현되어 있다. 업데이트 테스트 전에 별도 제거를 실행하지 않는다. 이 파일은 코드 서명이 없는 내부 테스트용이며 Windows 게시자·보안 경고가 나타날 수 있다. 공식 홈페이지나 고객에게 배포하지 않는다.

## 권장 테스트 순서

1. BLOW 계정으로 로그인하고 사용권이 유효한지 확인한다.
2. 블로그 세팅의 필수 정보를 저장한다. 기존 프로필에 새 필수 항목이 비어 있으면 입력한다.
3. 본인의 OpenAI API 키를 연결하고 네이버 블로그를 연결한다.
4. 첫 테스트는 한 글, 700자, 이미지·꾸미기 사용 안 함으로 설정한다. 주제·글 유형·기본 키워드·AI 모델·검토 깊이를 입력한다.
5. ‘이 글 자동 작성·저장’을 누르고 확인창에서 취소한다. 주제·키워드가 그대로 남는지 확인한다.
6. 같은 버튼을 다시 누르고 ‘자동 작성 시작’을 선택한다. 목록이 중복되지 않고 해당 글 한 개만 진행되는지 확인한다.
7. BLOW 창을 맨 앞으로 두고 처리 중에는 컴퓨터를 조작하거나 절전·종료하지 않는다.
8. 완료 후 네이버 임시저장 글에서 제목·본문을 확인한다. 최종 발행은 자동 실행하지 않는다.
9. 한 글 테스트가 성공한 다음 두 글을 각각 ‘목록에 추가’하고 목록 전체 실행을 확인한다. 이미지·꾸미기는 그다음 단계에서 하나씩 켠다.

실제 앱에서는 본인 OpenAI 계정에 사용료가 발생한다. 자동 검사는 글자 수·키워드 등 형식을 검사할 뿐 사실관계·표현·이미지 사용 권한을 보증하지 않는다. 저장 결과가 불확실하거나 중단되면 네이버에 이미 저장됐는지 먼저 확인하고 재시도를 결정한다.

## 검증 범위

- 전체 타입 검사 통과
- 단위 테스트 337개 통과
- 로컬 화면 검사 24개 통과
- 실제 공개 로그인 환경값을 사용한 데스크톱 빌드
- 실제 회원 로그인·유료 AI 생성·실제 네이버 저장·Windows 설치/업데이트 검수는 이 안내에 따라 별도 수행

브라우저의 localhost:4180 미리보기는 예시 데이터만 사용하는 디자인 검수 화면이다. 실제 프로그램 테스트는 설치한 BLOW에서 진행한다.
