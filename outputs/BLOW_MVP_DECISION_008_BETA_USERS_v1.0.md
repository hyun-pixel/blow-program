# BLOW MVP 결정 008 — 베타 사용자와 테스트 계정 운영

> 확인일: 2026-09-10
> 상태: 사용자 승인 완료
> 확정안: 협조 사용자 1명에게 무료 14일 베타 계정을 제공하고 총 3개 핵심 시나리오 검증
> 실행 제한: 실제 모집·초대·계정 생성·비용 지급은 별도 승인 전까지 하지 않음

## 1. 결정 대상

BLOW를 처음 사용할 베타 사용자 1명의 선정 기준, 계정 운영, 테스트 범위, 개인정보 보호와 통과 기준을 정한다.

베타는 제품을 홍보하거나 유료 판매하는 단계가 아니다. 실제 비개발자 한 명이 자신의 환경에서 설치부터 네이버 임시저장까지 완료할 수 있는지 확인하고 치명적인 오류를 찾는 제한된 흐름 검증 단계다. 한 명의 결과만으로 다양한 사용자 환경과 사용 방식을 대표할 수는 없다.

## 2. 확정 운영안

- 인원: 협조 가능한 사용자 1명
- 기간: 사용자별 첫 로그인부터 14일
- 이용료: 무료
- BLOW 계정: 사용자별 실제 이메일 계정 한 개
- 이용권: 관리자 발급 14일 베타 이용권
- 기기: 계정당 본인 PC 한 대
- 네이버: 사용자 본인의 계정과 본인이 관리하는 블로그
- OpenAI: 사용자 본인의 API 키
- 결과: 네이버 임시글까지만 저장하고 자동 최종 발행은 하지 않음
- 확대: 결과 검토 후 인원과 시점을 사용자에게 별도 승인받아 진행

공유 BLOW 계정, 공용 네이버 계정, 운영자가 만든 공용 OpenAI 키와 비밀번호 전달은 사용하지 않는다.

## 3. 사용자 구성

- 개발 과정에 참여하지 않은 비개발자 한 명을 우선한다.
- 본인이 관리하는 네이버 블로그와 본인 Windows PC로 직접 진행한다.
- 현재 개발 PC가 Windows 10 검증 기준이므로 가능하면 Windows 11 x64 사용자를 우선한다.
- 베타 사용자의 운영체제와 무관하게 Windows 10·11 호환성 검증은 별도 회귀 테스트로 유지한다.

## 4. 선정 조건

베타 사용자는 다음 조건을 모두 충족한다.

- 본인이 관리하는 네이버 블로그가 있다.
- 테스트 기간에 최소 세 번 직접 사용할 수 있다.
- 자신의 Windows PC와 최신 정식 Chrome을 사용한다.
- 자신의 OpenAI API 키를 준비하고 API 사용료 발생 가능성을 이해한다.
- 고객 개인정보, 의료·법률 사건 정보, 계약서와 영업비밀을 입력하지 않는다.
- 오류가 나면 작업을 멈추고 운영자에게 알려줄 수 있다.
- 임시글을 직접 확인한 뒤 발행 여부를 본인이 결정한다.
- 베타의 불안정성과 자료 삭제 가능성을 이해한다.
- 피드백과 진단 자료 제출은 선택이며 언제든 중단할 수 있다.

운영자 본인이나 개발 과정에 익숙한 사람보다 최초 설정을 설명 없이 시도할 비개발자를 우선한다.

## 5. 계정과 자격증명 원칙

### BLOW 계정

- 사용자별 실제 이메일로 가입하고 이메일 인증을 거친다.
- 관리자 화면에서 14일 베타 이용권을 부여한다.
- 계정당 PC 한 대와 블로그 한 개 제한을 그대로 적용한다.
- 베타 종료 후 유료 계정으로 자동 전환하거나 자동 결제하지 않는다.
- 계속 사용하지 않는 계정은 사용자 확인 후 삭제한다.

### 네이버 계정

- 사용자가 전용 Chrome에서 직접 로그인한다.
- 네이버 ID, 비밀번호, 일회용 인증번호를 운영자에게 전달하지 않는다.
- BLOW와 운영자는 로그인 정보를 읽거나 저장하지 않는다.
- 계정 보호 절차, CAPTCHA 또는 본인인증이 나타나면 자동화를 멈춘다.
- 가능하면 실제 고객 게시물이 아닌 별도의 안전한 임시글로 검증한다.

### OpenAI API 키

- 사용자가 자신의 키를 앱에 직접 입력한다.
- 키는 Windows 보안 저장소에만 보관한다.
- 운영자, 베타 담당자와 다른 사용자에게 키를 보내지 않는다.
- API 사용료는 사용자 계정에서 발생할 수 있음을 참여 전에 알린다.
- 테스트 종료 후 사용자가 앱에서 키를 삭제할 수 있게 한다.

## 6. 테스트 자료

모든 사용자에게 개인정보가 없는 공통 샘플 자료를 제공한다.

- 가상의 매장명과 소개
- 가상의 전화번호, 주소와 상담 링크
- 저작권 사용이 허용된 테스트 이미지
- 고객 이름·얼굴·연락처가 없는 내용
- 의료기록, 사건자료, 보험계약과 실제 상담 내용이 없는 원고

사용자는 실제 브랜드 정보로 추가 확인할 수 있지만 고객 개인정보, 제3자 비밀정보와 증거성 이미지를 넣지 않는다.

## 7. 사용자별 테스트 시나리오

사용자는 다음 세 가지를 한 번씩 수행한다. 총 목표는 3개 시나리오다.

### 시나리오 A — 기본 글

- 최초 설정
- 브랜드 프로필 입력
- 제목과 본문 생성
- 네이버 글쓰기 진입
- 임시저장 완료 확인

### 시나리오 B — 이미지와 서식

- 이미지 두 장 이상
- 개별사진·콜라주·슬라이드 중 하나
- 스티커, 구분선 또는 인용구 중 두 종류 이상
- 결과 순서 확인
- 임시저장 완료 확인

### 시나리오 C — 안전 중단과 복구

- 자동 입력 중 사용자가 의도적으로 한 번 개입
- 실제 자동화 중단과 안내 확인
- 앱을 다시 열어 새 작업 시작
- 네트워크 단절 또는 로그인 확인 필요 상황 한 가지
- 기존 글이 잘못 발행되거나 다른 블로그에 입력되지 않았는지 확인

최종 발행 버튼은 테스트 대상이 아니며 BLOW가 자동으로 조작해서는 안 된다.

## 8. 피드백 수집

행동 분석, 클릭 추적, 백그라운드 화면 녹화와 무단 로그 전송은 사용하지 않는다.

각 시나리오가 끝나면 다음 항목만 받는다.

- 베타 사용자 번호
- Windows와 Chrome 버전
- 성공·실패한 단계
- 사용자에게 보인 오류 문구
- 다시 시도했을 때 결과
- 1~5점 난이도
- 자유 의견

스크린샷과 진단 자료는 사용자가 내용을 확인하고 직접 보낼 때만 받는다. API 키, 네이버 계정, 본문, 고객 정보와 얼굴은 가리도록 안내한다. 원격 화면 공유가 필요하면 사용자가 보고 있는 상태에서 해당 지원 세션에 한해 동의를 받고 진행한다.

## 9. 즉시 중단 조건

다음 중 하나라도 발생하면 해당 사용자의 테스트와 신규 초대를 멈춘다.

- BLOW가 최종 발행을 시도하거나 실행함
- 다른 블로그 또는 다른 글에 입력함
- 네이버 비밀번호, API 키나 세션이 서버·로그에 남음
- 사용자 동작 이후에도 자동화가 계속됨
- 동일 작업이 무한 반복됨
- 원본 이미지 또는 기존 게시물을 삭제·변경함
- 네이버 계정 제한이나 비정상 활동 경고가 발생함
- 관리자 권한 없이 다른 회원 정보에 접근 가능함

원인과 영향 범위를 확인하고 수정·회귀 테스트를 통과하기 전에는 베타를 재개하지 않는다.

## 10. 통과 기준

- BETA-01: 사용자 한 명이 자신의 계정과 PC로 가입·로그인을 완료한다.
- BETA-02: 사용자가 운영자의 비밀번호 입력이나 원격 조작 없이 최초 설정을 완료한다.
- BETA-03: 총 3개 시나리오 모두 확인된 네이버 임시저장까지 완료된다.
- BETA-04: 사용자가 세 가지 시나리오를 독립적으로 완료한다.
- BETA-05: 자동 최종 발행은 0건이다.
- BETA-06: 잘못된 블로그·글 입력과 원본 파일 변경은 0건이다.
- BETA-07: API 키, 네이버 인증정보와 글 내용의 서버 전송은 0건이다.
- BETA-08: 사용자 개입 뒤 남은 자동 조작이 모두 중단된다.
- BETA-09: 치명적 오류와 보안 오류가 미해결 상태로 남지 않는다.
- BETA-10: 한 명의 결과를 검토하고 기록한 뒤 추가 베타 인원과 시점을 별도로 결정한다.

## 11. 데이터 보관과 종료

- 서버에는 기존 PRD가 허용한 이메일, 이용권, 기기 해시와 최소 보안 기록만 저장한다.
- 본문, 이미지, OpenAI API 키와 네이버 로그인 정보는 서버에 저장하지 않는다.
- 설문과 오류 기록은 베타 사용자 번호로 관리하고 계정 이메일과 분리한다.
- 스크린샷 원본은 문제 해결 후 30일 안에 삭제하고 민감정보가 제거된 기술 요약만 남긴다.
- 베타 종료 후 사용자가 계속 사용하지 않으면 계정과 로컬 데이터 삭제 방법을 안내한다.
- 사용자는 언제든 참여를 중단하고 제공한 피드백 원본 삭제를 요청할 수 있다.

## 12. 사용자에게 미리 알릴 내용

- 시험 버전이라 오류와 데이터 삭제가 발생할 수 있음
- 네이버 임시저장 결과를 반드시 직접 확인해야 함
- 자동 최종 발행을 하지 않음
- OpenAI API 사용료가 사용자에게 발생할 수 있음
- 고객 개인정보와 영업비밀을 입력하지 않아야 함
- 오류 자료 제출과 화면 공유는 선택 사항임
- 계정은 14일 뒤 자동 결제 없이 만료됨
- 언제든 테스트를 중단할 수 있음

## 13. 지금 실행하지 않는 작업

- 베타 사용자 모집과 연락
- 이메일 초대와 BLOW 계정 생성
- 네이버·OpenAI 계정 또는 API 키 대여
- 베타 참가비 청구와 자동 유료 전환
- 사례비 약속 또는 지급
- 사용자 PC 원격 접속
- 스크린샷·진단자료 자동 수집
- 추가 인원 확대와 유료 판매

## 14. 실행 전 확인 사항

실제 베타를 시작하기 전에 다음이 준비되어야 한다.

1. 계정·이용권·기기 제한과 관리자 기능
2. 이메일 인증과 비밀번호 재설정
3. Windows 설치 파일과 코드 서명
4. 개인정보·이용약관·베타 안내
5. 긴급 중지와 필수 업데이트
6. Windows 10·11 실제 PC 회귀 테스트
7. 고객지원 연락처와 중단 공지 방법
8. 참가자 모집 문구와 공통 샘플 자료

## 15. 비용과 승인

- 베타 계정 자체는 무료로 제공한다.
- 각 사용자의 OpenAI API 사용료가 소액 발생할 수 있다.
- 사례비, 장비, Windows 라이선스와 원격지원 도구 비용은 이 결정에 포함하지 않는다.
- 실제 모집, 외부 연락, 비용 약속과 개인정보 수집은 사용자의 별도 승인 후 진행한다.
