# BLOW POC 작업대 화면 규칙

> 상위 기준: `design-system/blow/MASTER.md`
> 적용 화면: 자동 입력 기술검증 작업대

이 화면은 사용자가 승인한 `BLOW_UIUX_REDESIGN_DIRECTION_v2.0.md`와 고해상도 프로토타입을 우선 반영한다.

## 상위 기준 보완

- 형태: 일반 카드 중심 대시보드가 아닌 문서 작업대 구조
- 사이드바: 208px, 얇은 경계선과 전체 높이 메뉴
- 모서리: 기본 제어 6px, 작업 영역 4px, 대화상자 8px
- 그림자: 대화상자와 토스트에만 사용
- 색상: 회색 기반 단색 화면과 짙은 파란색 단일 강조색
- 모션: 상태 변경을 설명하는 150ms 색상·투명도 전환만 허용
- 정보 밀도: 한 화면에서 작업 조건과 현재 상태를 함께 확인
- 테마: POC에서는 운영체제 설정에 따른 라이트·다크 모드를 검증하되 한 화면 안에서 테마를 혼용하지 않음

## 접근성

- 주요 조작 높이 44px 이상
- 포커스 외곽선은 즉시 표시
- 진행 상태는 `aria-live="polite"`로 전달
- 오류와 성공은 색상뿐 아니라 아이콘, 제목, 설명으로 구분
- 200% 확대에서 두 열을 한 열로 재배치
## 네이버 연결 화면

- 주소 입력과 연결 순서를 2열 작업대로 보여주고, 980px 이하에서는 입력 다음에 상태 순서를 배치한다.
- 전용 Chrome이 열린 동안 주소 입력을 잠가 현재 세션과 등록 주소가 달라지지 않게 한다.
- 비밀번호 입력칸은 앱에 만들지 않으며 사용자의 Chrome 수동 로그인을 명시한다.
- 오류는 상단 요약과 해당 주소 필드에 표시하되 보조기기 알림은 한 번만 전달한다.
- 모바일 메뉴 세 개는 같은 너비로 배치하고 44px 이상의 조작 영역을 유지한다.
